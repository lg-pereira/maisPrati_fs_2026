# Frameworks

## CSS

- Tailwind (mais comum hoje com Vibe Coding)
  - é um framework CSS que usa classes para estilizar os elementos html
  - é mais leve que o Bootstrap
  - é mais flexível que o Bootstrap

- Bootstrap
  - é um framework CSS que usa classes para estilizar os elementos html
  - é mais leve que o Tailwind
  - é menos flexível que o Tailwind
  - é mais rápido de aprender do que o Tailwind
