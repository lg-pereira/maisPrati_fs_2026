# Formação Full Stack — +PraTi

Repositório de estudos do curso **Formação Full Stack Jr.** oferecido pela [+PraTi](https://maisprati.com.br), com foco em desenvolvimento web completo.

## Tecnologias do curso

**Front-end:** HTML · CSS · JavaScript · React  
**Back-end:** Java

---

## Estrutura do repositório

### Módulo 1 — JavaScript (Fundamentos)

Introdução à programação com JavaScript puro rodando em Node.js.

| Arquivo                  | Conteúdo                                                                                                   |
| ------------------------ | ---------------------------------------------------------------------------------------------------------- |
| `aula_3-4.js`            | Variáveis (`var`, `let`, `const`), tipos de dados, operadores aritméticos, relacionais, lógicos e ternário |
| `aula_5.js`              | Exercícios de fixação de operadores                                                                        |
| `aula_8.js`              | Estruturas de controle                                                                                     |
| `aula_9-10.js`           | Laços de repetição                                                                                         |
| `aula_11-12.js`          | Arrays e vetores                                                                                           |
| `exercicio_funcoes.js`   | Funções com parâmetros e retorno: cálculo de média, validação de idade, calculadora com `switch`           |
| `exercicio_tabuada.js`   | Geração de tabuada com laços                                                                               |
| `exercicio_vetor.js`     | Manipulação de arrays                                                                                      |
| `exercicio_queue-deq.js` | Estruturas de dados: Fila (FIFO) para impressora e Deque (fila duplamente terminada)                       |
| `lista_exercícios1-2.js` | Lista de exercícios 1 e 2                                                                                  |
| `lista_exercicios3.js`   | Lista de exercícios 3: objetos, propriedades, laço `for...in`, arrays e desconto                           |

**Dependência:** [`prompt-sync`](https://www.npmjs.com/package/prompt-sync) — leitura de input no terminal.

---

### Módulo 2 — HTML (Fundamentos)

Introdução ao desenvolvimento web com HTML5.

| Arquivo      | Conteúdo                                                                                                                            |
| ------------ | ----------------------------------------------------------------------------------------------------------------------------------- |
| `index.html` | Primeira página HTML: estrutura básica (`DOCTYPE`, `head`, `body`), tags `h1`, `h2`, `p`, `ul`/`li`, atributos de idioma e viewport |
